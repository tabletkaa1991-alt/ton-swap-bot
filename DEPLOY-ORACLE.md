# Переезд на Oracle Cloud Always Free (бесплатно, 24/7)

> Актуально после правок: бот теперь **один контейнер** — он сам отдаёт мини-приложение,
> `/api/*` и вебхук; Caddy в `deploy/Caddyfile` только терминирует TLS и проксирует на `bot:8080`.
> Манифест TON Connect и кнопка меню собираются из `WEBAPP_URL` автоматически, руками
> `webapp/tonconnect-manifest.json` править не нужно. Установка — по-прежнему
> `DOMAIN=ваш-домен bash deploy/install.sh`. Альтернативы без карты — в `DEPLOY-FREE.md`.

Пошагово: что делаешь ты → что делаю я. Ключ уже сгенерирован, ничего придумывать не надо.

---

## Шаг 1. Регистрация (10 минут, только ты)

1. Открой https://signup.cloud.oracle.com
2. Email, пароль, страна (укажи ту, к которой есть карта и адрес).
3. **Карта**: нужна для верификации — списывают ~$1 и возвращают. Российские карты почти всегда отклоняются, нужна зарубежная или виртуальная (например, выпущенная на зарубежный счёт).
4. **Home Region**: выбери один и запомни — бесплатные ресурсы доступны только в нём. Для России ближе Frankfurt/Amsterdam, но там чаще нет свободных ARM-мощностей.
5. Дождись письма «Your Oracle Cloud account is ready».

### Если регистрацию отклонили
- Другая карта / другой email / другой регион (частая практика — попробовать 2–3 раза).
- Альтернативы с бесплатным/дешёвым стартом: Google Cloud ($300 на 90 дней), Azure ($200 на 30 дней), любой VPS за 200–400 ₽.

## Шаг 2. Создать сервер (5 минут, только ты)

Меню → **Compute → Instances → Create instance**.

| Поле | Значение |
|---|---|
| Name | `fastobmennik` |
| Image | **Canonical Ubuntu 24.04** (не Oracle Linux!) |
| Shape | **VM.Standard.E2.1.Micro** (AMD, 1 CPU / 1 ГБ) — проще получить, чем ARM |
| Primary network | оставь как предложено (создаст VCN) |
| Public IP | **Assign a public IPv4 address** — обязательно |
| SSH keys | **Paste public key** → вставь строку ниже |

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIBIxKGg2FLaRItJwOVh21oBlMp4soSFkg0S2mhzB0B3w fastobmennik-oracle
```

Нажми **Create**. Через 1–2 минуты инстанс станет `RUNNING`.

**Запиши публичный IP** — он на странице инстанса, в разделе *Primary VNIC → Public IPv4 address*.

### Если пишет «Out of capacity»
- Попробуй другой **Availability Domain** (AD-1/AD-2/AD-3) — часто помогает.
- Или shape `VM.Standard.A1.Flex` с 1 OCPU / 6 ГБ (ARM, бесплатный лимит до 4 OCPU / 24 ГБ).
- Или подожди и повтори позже — мощности освобождаются.

## Шаг 3. Открыть порты (2 минуты, только ты)

Без этого сайт не получит HTTPS-сертификат.

1. На странице инстанса: **Primary VNIC → Subnet → Security Lists → Default Security List**.
2. **Add Ingress Rules** и добавь две:
   - Source `0.0.0.0/0`, IP Protocol `TCP`, Destination Port Range `80`
   - Source `0.0.0.0/0`, IP Protocol `TCP`, Destination Port Range `443`

Внутренний фаервол (iptables) я открою сам при подключении.

---

## Шаг 4. Бесплатный домен (3 минуты, только ты)

Свой домен покупать не надо — DuckDNS даёт поддомен бесплатно и Let's Encrypt выпускает на него сертификат.

1. https://www.duckdns.org → войди через GitHub/Google.
2. Придумай имя, например `fastobmennik` → **add domain**. Получится `fastobmennik.duckdns.org`.
3. В поле **current ip** впиши публичный IP сервера из шага 2 → **update ip**.

Проверка: открой `http://fastobmennik.duckdns.org` — если не открывается, подожди пару минут (DNS обновляется).

## Шаг 5. Прислать мне (1 минута)

Скажи в чат три вещи:

```
ip: <публичный IP>
domain: <имя>.duckdns.org
ключ: C:\bat\oracle\key
```

Пароль не нужен: вход по ключу, приватная часть лежит у тебя (`C:\bat\oracle\key`), публичную ты вставил в Oracle. Мне достаточно пути к файлу.

## Что сделаю я (10–15 минут, без твоего участия)

1. Подключусь по SSH, проверю версию Ubuntu и доступ в интернет.
2. Открою порты 80/443 во внутреннем фаерволе.
3. Поставлю Docker.
4. Скопирую проект, подставлю домен в `.env`, `deploy/Caddyfile` и манифест TON Connect.
5. Подниму контейнеры: бот + Caddy (HTTPS сам).
6. Проверю по факту: `getMe`, `/api/health`, страницу мини-приложения по HTTPS, манифест.
7. Обновлю кнопку меню бота на новый адрес.
8. Настрою автозапуск (Docker `restart: unless-stopped`) — сервер перезагрузился, всё поднялось само.
9. Пришлю чек-лист проверки: что открыть, что нажать, что должно прийти в чат.

## После переезда

- Ноутбук можно выключать — бот живёт на сервере.
- `start.ps1` больше не нужен.
- Ссылка мини-приложения становится постоянной (домен DuckDNS), телеграм-кнопка меню обновится один раз.
- Токен бота и ключ tonapi остаются те же.

## Важно про деньги

Always Free — это правда бесплатно, но:
- не создавай ресурсы вне «Always Free» (платные shape, большие диски) — за них списывают;
- раз в месяц Oracle может «усыплять» простаивающие AMD-инстансы (reclaim) — если бот перестанет отвечать, я подниму его снова, данные в Docker-томах сохранятся;
- держи карту, привязанную к аккаунту, активной — иначе аккаунт могут приостановить.
